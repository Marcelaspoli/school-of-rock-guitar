# School of Rock Guitar 🎸🎶

This is an interactive guitar made in Godot 4 for my 1st Year Project on Creative Coding. You can play strings and chords with your keyboard, use the whammy bar, and adjust the amp effects. There are no audio files, all the sound is generated by code.



## Controls

| Input | Action |
|---|---|
| 1 – 6 | pluck a string (1 = low E, 6 = high e) |
| Q | Em chord |
| W | Am chord |
| E | G chord |
| R | D chord |
| T | A chord |
| Y | E chord |
| hold SPACE + move mouse up/down | whammy bar (bends the pitch) |
| SHRED MODE button | plays a random pentatonic riff by itself |



## Effects Panel

| Slider | what it does |
|---|---|
| Distortion | how much overdrive |
| Reverb | adds reverb/room sound |
| Delay | echo |
| Volume | volume |



## How the sound works

The audio is generated sample by sample using Godot's AudioStreamGenerator. each string uses something called **Karplus-Strong synthesis** which i looked up — basically you fill a small buffer with random noise and then run a low-pass filter in a loop. it naturally decays in a way that sounds like a plucked string. bass strings take longer to fade out, high strings go away faster.


- the wound strings (E A D G) decay slower than the plain ones
- letting go of a key mutes the string quickly
- the whammy bar uses a fractional delay so the pitch bends smoothly instead of jumping
- there's a small overdrive and reverb on a separate audio bus



## Visuals

The guitar body has a cherry finish made by drawing 4 polygons scaled to different sizes on top of each other, dark on the outside and amber in the middle. the string thicknesses and colors are based on what real guitar strings actually look like (low E is thick and bronze, high e is thin and silver). fret positions use equal temperament math instead of just evenly spacing them.



## File structure

```
school-of-rock-guitar/
├── project.godot       godot project config
├── Main.tscn           main scene
├── Main.gd             connects everything together
├── Guitar.tscn         the guitar node
├── Guitar.gd           drawing, input, signals
├── AudioEngine.gd      autoload — handles all the synthesis and effects
├── Sequencer.gd        autoload — shred mode riff generator
├── Visualizer.gd       background effects (lights, crowd, sparks etc)
├── UI.tscn             the hud
├── UI.gd               sliders and chord display
└── README.md
```



## How to run it

1. download Godot 4.2 or newer from godotengine.org
2. open Godot, click Import, pick the project.godot file from this folder
3. hit F5
